#  🚀 *Project Update:  Spotify Project Front-End Study*

## 📌 Introduction
Welcome to the **Spotify-Themed Project**! This project is a static web interface designed to mimic the layout and styling of Spotify, built using **HTML and CSS only**.

## 💡 Overview Report
This project demonstrates the ability to replicate Spotify’s user interface with pure HTML and CSS. It focuses on designing a clean and visually appealing layout without using JavaScript or making the site responsive.

## 📂 Project Structure
```
Spotify/
├── 🎨images/          # Directory containing image assets
├── 📄 Spotify.css      # Stylesheet for the project
└── 🎨 Spotify.html     # Main HTML file

```

## 🔶 Highlight Features
- **Homepage**: Includes a sidebar with icons for **Home, Search, and Saved Playlists**.
- **Playlists**: A dedicated section for creating and viewing playlists.
- **Podcast Section**: Displays a grid of podcast covers with titles and images.
- **Top Navigation**: Includes buttons for **Notifications, Sharing, Friends, and Account Settings**.
- **Custom Scrollbars**: Styled scrollbars for a seamless experience.

## 🛠️ Technologies Used
- **HTML**: Structure and layout of the web pages.
- **CSS**: Styling and design implementation.

## 📥 Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/MuaddhAlsway/Spotify.git
   ```
2. Navigate to the project folder:
   ```sh
   cd Spotify..
   ```
3. Open `index.html` in your browser
